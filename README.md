# Timer Tree

A calming Pomodoro-style focus timer that grows virtual plants as you complete focus sessions.

Live app: [timertree.ca](http://timertree.ca/)

## Features

- Custom focus intervals with quick presets
- Pomodoro mode with configurable regular and extended breaks
- Break modal with skip and snooze controls
- Plant selection, growth stages, and garden history
- Daily goals, streaks, weekly stats, and data export
- Session tags, sound themes, volume controls, dark mode, and keyboard shortcuts

## Tech

HTML · CSS · JavaScript

## Development

This is a static GitHub Pages app served from the `docs/` directory. Open `docs/index.html` directly or serve the folder locally to test changes.
